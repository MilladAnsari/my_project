Project Title: Development of a Graphical IoT Gateway with CAN on ESP32 using MicroPython for Smart Home

Overview:
This repository contains the source code, firmware, and documentation for a Graphical IoT Gateway designed for smart home environments. Built on the ESP32-S3-Touch platform using MicroPython, this project addresses the interoperability challenges of IoT protocols by bridging local CAN bus networks with the ThingsBoard IoT platform for seamless data monitoring and real-time control.

Furthermore, it features an interactive HMI developed with the LVGL library. A significant focus of this research is overcoming the inherent limitations of microcontrollers compared to Single Board Computers (SBCs)—such as strict memory/CPU constraints, absence of a full OS, and the need for precise resource management and low-level driver handling.
